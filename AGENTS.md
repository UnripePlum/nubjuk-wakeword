# Codex Project Rules (wakeword)

## Scope

- Applies to all Codex responses and code changes in this repository.

## Communication Rule

- If a response includes AI/ML specialist terminology that a non-specialist might not know, add a short explanation section at the end of the response.
- Put this section at the very end, using a clear label such as `Terminology`.
- Keep explanations concise, one line per term, and focused on terms actually used in that response.
